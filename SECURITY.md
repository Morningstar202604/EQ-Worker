# Security Policy

We support GitHub's private vulnerability reporting: open Repository → Security → Report a vulnerability. Reports are handled as soon as possible. Please do not disclose vulnerability details publicly.

This repository, **EQ-Worker (EQ-Worker)**, is a local-first relationship management tool (人脉经营工具) that runs fully on the user's device. All data (persons, events, reminders, progress) is stored in local storage (browser localStorage / WeChat mini-program local cache) and never leaves the device — no server, no account, no tracking.
