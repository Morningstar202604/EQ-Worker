**完整描述**
```
EQ-Worker是一款「人脉经营」工具，不是答题测评。

【核心玩法】
记录往来 → 自动画像 → 智能提醒 → 情景修炼 → 年度报告

【五个模块】
· 雷达总览：五维画像（人脉规模／人情热度／往来频率／人情信用／处世智慧）+ 人情指数 + 今日提醒
· 人脉管理：每人一张雷达卡，热度 = 事件加权 + 90 天半衰期衰减，到期自动提醒该走动
· 快速记录：饭局、随礼、借钱、互助、深聊…10 类事件自动带人情值，10 秒记一笔，可撤销
· 修炼场：15 个中国式社交情景（随礼／挡酒／借钱／救场／圆场…），难度分级，练完涨段位
· 数据中心：月度洞察、近 6 月趋势、年度人情报告、待办管理、备份迁移

【你会用到它的时刻】
· 饭局散场，记一笔谁请了客
· 收到婚礼请柬，翻出对方当年随了多少
· 忘了好友生日，雷达提前 7 天提醒你
· 年末想知道这一年人情往来是什么节奏

【关于隐私】
数据只存在你的设备上，不申请存储权限、不上传服务器、无需注册账号。
应用内提供 JSON / CSV / 剪贴板三种备份方式，换设备也带得走。
卸载应用会清除数据，请记得先备份。

【许可】
本项目以 CC BY-NC 4.0 发布：可自由使用与分享，禁止商业性转售。
```

## 三、隐私政策（上架必需，可直接粘贴）

```
隐私政策

生效日期：2026-10-18

1. 我们收集什么
   不收集。EQ-Worker没有服务器、没有账号系统、没有数据统计或崩溃上报。

2. 数据存在哪里
   你记录的所有人脉、往来、待办数据只保存在你自己的设备上
   （安卓：应用私有目录；Windows：应用用户数据目录）。

3. 我们上传到哪里
   任何地方都不上传。应用不具备网络上传能力，联网权限仅用于极端情况下的字体回退加载。

4. 我们申请哪些权限
   · 安卓：仅 INTERNET（离线字体镜像兜底）。不申请通讯录、位置、存储、相机中的任何一项。
   · Windows：不申请任何特殊权限。

5. 数据备份与清除
   应用内提供 JSON 备份、CSV 导出与剪贴板复制三种方式，由你自行保管。
   卸载应用将永久清除本地数据，请先完成备份。

6. 儿童隐私
   本应用不面向 13 岁以下儿童，也不会主动收集任何年龄段用户的个人信息。

7. 变更
   如隐私政策调整，会在应用与仓库中同步更新。

联系：通过项目仓库的 Issue 反馈。
```
