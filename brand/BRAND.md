# EQ-Worker · 品牌规范（BRAND GUIDELINES）

> 版本 1.0 ｜ 2026-10-18 ｜ 适用：安卓 / Windows / 网页 / 小程序 / 官网 / 宣传物料

## 一、品牌核心

| 项 | 内容 |
|---|---|
| 中文名 | **EQ-Worker** |
| 英文标识 | **EQ · WORKER** |
| Slogan | 把人情账记明白，把关系经营成细水长流 |
| 定位 | 人脉经营工具（不是答题测评）：记录往来 → 自动画像 → 智能提醒 → 情景修炼 → 年度报告 |
| 关键词 | 人情账本 · 本地优先 · 隐私至上 · 中国式社交 |

## 二、图形标识

**主图形 = 五维雷达**：三层五边形网格代表五维画像（人脉规模 / 人情热度 / 往来频率 / 人情信用 / 处世智慧），金色圆心代表"每一笔人情"。

| 文件 | 用途 |
|---|---|
| `logo-icon.svg` | 应用图标、头像（方形，含纸底圆） |
| `logo-horizontal.svg` | 横版字标：官网头图、商店横幅、文档页眉 |
| `logo-mono.svg` | 单色版（颜色随 `currentColor`），印章 / 深浅底通吃 |

**使用规则**
- 最小尺寸：方形 ≥ 24px，横版 ≥ 120px 宽
- 留白：标识四周保留 ≥ 图标高度 1/10 的净空
- 禁止：拉伸变形、换字体加粗、把数据区改成其他形状、加投影描边

## 四、字体

| 场景 | 字体 | 备注 |
|---|---|---|
| 品牌字标 / 标题 | 楷书：Ma Shan Zheng → KaiTi → STKaiti | 日记本气质，需回退链 |
| 正文 / 数据 | 衬线：Noto Serif SC → Songti SC → SimSun | 中文排版稳妥 |
| 西文点缀 | Georgia / 衬线族 | EQ · WORKER 用大字距（letter-spacing ≥ 0.4em） |

## 五、应用图标与启动页

- 安卓：`dist/android/`（方形 + 圆形各 5 密度；自适应图标前景 `ic_launcher_foreground.png`，背景色 `#f6f1e4`）
- Windows：`dist/windows/app.ico`（16–256 全尺寸）
- 启动页：纸底 `#f6f1e4` + 图标居中（`splash.png` / `splash_icon.png`），**不加 Slogan 文字**（保持安静的第一秒）

## 六、文案语气

- 用"人情账、走动、还礼、经营"等生活词，不用"CRM、用户、管理"等系统词
- 提醒文案像朋友口吻：「该去看看老张了，上个月他帮过你」
- 数字报告克制、不评判：只呈现事实与节奏，不说教
